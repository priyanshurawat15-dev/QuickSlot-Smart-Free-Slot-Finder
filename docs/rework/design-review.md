# GEHU visual reference review

Reviewed the official homepage, Dehradun landing page and Student Area on 20 October 2026. Scrolled through the campus cards, institutional text columns, article/event grids, notices, service links and footers, beyond the hero/video.

Sources: https://gehu.ac.in/ ; https://gehu.ac.in/dehradun/ ; https://gehu.ac.in/dehradun/student-area/

Observed patterns: charcoal masthead and footer; white navigation text on dark surfaces; consistently aligned content widths; clear equal-column grids; generous vertical spacing; plain dark headings; gray body text. The Dehradun Student Area uses Manrope and computed body color #6b6b6b. Following the user's latest review, QuickSlot uses compact charcoal glass headers and footers inspired by the provided Aarambh 4.0 project, an original SVG university emblem and live text without campus names in the brand. Green free and red booked/in-use cards add meaningful color; schedules without confirmed completeness use neutral cards and keep their backend guards. Confirmed floors and actual room labels appear on each compact card. The application uses Aarambh's Outfit typeface, dark neutral text, warm paper surfaces and strong purple controls. Blue text and blue-tinted panels are removed; status colors remain semantic. Doodles and gradients are removed.

The QuickSlot route review covers the full room finder, room details, login, request form, requester history, coordinator queue, HOD queue, teacher schedules, timetable register and room register on desktop and mobile. Automated checks scroll each route to its footer, check horizontal overflow and exercise real API-backed role workflows. Evidence remains in ignored test output; no test data is presented as verified campus schedule coverage.

Club profile data comes from data/organizers.js, pages/AboutPage.js and common/Footer.js. Only public club profile content is reused; event phone contacts and unrelated files are not copied.

The latest refinement uses larger dark text, solid #5b19d1 primary controls and consistent keyboard/touch dropdowns. Public verification labels are removed while backend coverage checks remain.
